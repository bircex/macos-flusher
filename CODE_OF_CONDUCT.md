# Code of Conduct

This is a small open source project. The expectation is simple: be respectful in issues, pull requests and discussions. Disagree with the code, not the person.

Not acceptable: harassment, insults, discriminatory language or jokes, or publishing someone else's private information.

If someone is not following this, report it by opening an issue addressed to the maintainer, or, if it is sensitive, through a [private security advisory](https://github.com/bircex/macos-flusher/security/advisories/new). Reports are handled by the project maintainer, who may edit, remove or lock content, or block a contributor, as needed.

This is written in the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/) without reproducing its full text.
